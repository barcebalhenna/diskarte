# Diskarte

A 2D-pixel-art neighborhood life-sim that teaches financial literacy and
online-gambling awareness — by letting you explore everyday choices. Walk
around a compact barangay, talk to locals, and return home to manage a weekly
budget. School game-based-learning prototype. Portrait, offline, vanilla
HTML/CSS/JS.

## Run it
1. Open this folder in **VS Code**.
2. Install the **Live Server** extension (if you haven't).
3. Right-click `index.html` → **Open with Live Server** (or just double-click
   `index.html`).
4. Choose Play — Sandbox, then move with WASD / arrow keys or the on-screen
   directional pad. Walk near a place and press E / Enter or tap Interact.
   You can also tap a building to visit it. Return to Bahay to plan the week.

## Build it (with Claude Code)
Follow `diskarte_build_plan.md` one milestone at a time. `CLAUDE.md` gives
Claude Code the full context — it's read automatically each session.

**Status:** The three-week budgeting loop and scripted paths are playable. The
Week Hub is now a small, explorable neighborhood; its locations add flavor
and context while the existing weekly budget, event, and debrief systems run
as before.

## Important
Educational only. No real money, no real gambling. Winning the game means
ending the month with savings, an intact scholarship, and self-control —
never by gambling.
