# Diskarte

A 2D-pixel-art budget life-sim that teaches financial literacy and
online-gambling awareness — by letting you feel the trap. School game-based-
learning prototype. Portrait, offline, vanilla HTML/CSS/JS.

## Run it
1. Open this folder in **VS Code**.
2. Install the **Live Server** extension (if you haven't).
3. Right-click `index.html` → **Open with Live Server** (or just double-click
   `index.html`).
4. You'll land on the Title screen and can click through all 11 screens.

## Build it (with Claude Code)
Follow `diskarte_build_plan.md` one milestone at a time. `CLAUDE.md` gives
Claude Code the full context — it's read automatically each session.

## Important
Educational only. No real money, no real gambling. Winning the game means
ending the month with savings, an intact scholarship, and self-control —
never by gambling.
